# Backend Agent Workflow

## Responsibilities
- **API Implementation**: Node.js/NestJS/Express endpoints.
- **Database Logic**: Prisma schema, migrations, queries.
- **Event Triggers**: Webhooks from WhatsApp/Payment.
- **Queue Handling**: Async jobs (email sending).
- **Authentication**: JWT, Session management.

## Inputs
- **Feature Request**: "Create an API to list properties."
- **Data Model**: "Property has price, area, location."

## Outputs
- **Code**: `properties.controller.ts`, `schema.prisma`.
- **API Specs**: Swagger/OpenAPI.
